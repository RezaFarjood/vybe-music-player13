# VYBE v0.5.0 — Windows + Android

این سورس یکپارچه Flutter نسخه 0.5.0 است. **زبان رابط کاربری انگلیسی باقی مانده** و فونت خوانای فارسی برای اطلاعات آهنگ‌ها حفظ شده است.

## چه چیزهایی تغییر کرده‌اند؟

### Android — بهبود عملکرد در سراسر اپ

- تغییر معماری بروزرسانی موقعیت آهنگ: فقط کنترل پیشرفت پخش بروزرسانی می‌شود؛ Home، Library و Navigation دیگر با هر تیک موقعیت آهنگ دوباره ساخته نمی‌شوند.
- به‌روزرسانی Metadata در گروه‌های ۲۴تایی روی isolate و کاهش دفعات بازسازی کتابخانه.
- محدودکردن خواندن همزمان کاورهای واقعی به دو کار پس‌زمینه؛ کش کنترل‌شده و محدودیت حافظه.
- حذف Blur زنده سنگین از تعداد زیاد پنل‌ها و حفظ ظاهر شیشه‌ای با گرادیان و کنتراست مناسب.
- فهرست Songs با ساخت تنبل، ارتفاع مشخص برای هر ردیف و محدوده کش محدود.
- جست‌وجوی فارسی/انگلیسی با تأخیر کوتاه ۱۱۰ میلی‌ثانیه برای فیلتر، بدون تأخیر در ثبت متن در TextField.
- انیمیشن جابجایی تب‌ها کوتاه‌تر (۱۵۵ ms) و ناوبری مسیرهای کامل با حس iOS.
- Workflow اندروید APK آزمایشی بهینه‌شده Release/AOT می‌سازد، نه Debug. این تفاوت برای روانی روی دستگاه واقعی اهمیت دارد.

### Android — ظاهر و عملکرد

- مسیر `Appearance` و پنل‌های مدیریت آهنگ اصلاح شده است؛ هر ۱۵ تم واقعی در بخش Appearance قابل انتخاب و ذخیره هستند.
- `Online` در Settings به تب Online داخلی می‌رود؛ سایت پیش‌فرض BeatMastering و سه سایت جایگزین مطابق نسخه قبلی باقی مانده‌اند.
- نوار ناوبری و مینی‌پلیر به بالای ناحیه سیستم (`SafeArea`) منتقل شدند و هنگام بازشدن کیبورد کنار می‌روند.
- لمس مینی‌پلیر صفحه کامل Now Playing با کاور، Seek، Like، Shuffle، Repeat، صف پخش، Play/Pause، Previous/Next باز می‌کند؛ خود مینی‌پلیر حفظ شده است.
- صفحه شروع VYBE با لوگوی اصلی و نشان پیشرفت فقط تا پایان بارگذاری اطلاعات ضروری نمایش داده می‌شود؛ هیچ مکث مصنوعی اضافه نشده. Splash بومی اندروید نیز لوگو و پس‌زمینه هماهنگ دارد.
- رابط، برچسب‌ها و منوها انگلیسی‌اند.

### Android — صدا و کنترل سیستم

- صدای **داخلی پخش‌کننده اندروید** به‌طور پیش‌فرض ۱۰۰٪ (gain unity) است؛ نسخه قبلی ۷۰٪ بود. میزان انتخابی کاربر ذخیره می‌شود.
- گزینه `Audio & Playback` شامل تغییر Playback Level و `ReplayGain` اختیاری است. ReplayGain فقط وقتی اطلاعات آن در فایل باشد تراز بلندی را تنظیم می‌کند؛ جلوگیری از کلیپ‌شدن فعال است و افزایش مصنوعی برای فایل‌های بدون تگ انجام نمی‌شود. مقدار اولیه OFF است تا فایل بدون پردازش اضافی پخش شود.
- اضافه‌شدن `audio_service 0.18.19` و `audio_session 0.2.4` برای کنترل‌های MediaSession، اعلان/لاک‌اسکرین، دکمه‌های هدفون و مدیریت Audio Focus. تصاویر کاور در حد امکان به MediaSession ارسال می‌شوند. ظاهر دقیق لاک‌اسکرین را نسخه Android/One UI تعیین می‌کند.
- خود فایل موسیقی تغییر یا بازنویسی نمی‌شود؛ ارتقای فرمت یا بازیابی کیفیت از دست‌رفته در فایل فشرده ادعا نمی‌شود.

### Windows

- مطابق خواسته فقط اسکرول‌بار محتوای اصلی `thumbVisibility=true`, `interactive=true` و ScrollController اختصاصی گرفته است تا با موس کشیده شود؛ باقی رابط تأییدشده حفظ شده است. سطح صدای پیش‌فرض ویندوز همان ۷۰٪ قبلی است، مگر کاربر خودش مقدار دیگری انتخاب و ذخیره کند.

## Build در GitHub Actions

- `.github/workflows/windows.yml`: نسخه ویندوز Release، فایل اجرایی به‌همراه پوشه و DLL و گزارش SHA256.
- `.github/workflows/android.yml`: نسخه Android **release-preview APK** که برای آزمون عملکرد روی گوشی از Debug روان‌تر است. در Flutter template ممکن است با کلید آزمایشی Debug امضا شود؛ **برای انتشار عمومی یا Google Play مناسب نیست**.
- نسخه ثابت Flutter `3.47.7`، Java `17`، Android compileSdk `36` و پکیج اصلاح‌شده `google_fonts 6.3.3`.
- برای آپلود دستی فایل‌ها، فایل‌های داخل ZIP را در **ریشه** مخزن بگذارید؛ `.github/workflows` مخفی است و نباید جا بیفتد.

## نصب APK و محافظت امنیتی

در بعضی گوشی‌ها اگر نسخه آزمایشی جدید با امضای متفاوت روی نصب قبلی نصب شود، خطای `INSTALL_FAILED_UPDATE_INCOMPATIBLE` رخ می‌دهد. در صورت تمایل به حذف نصب قبلی، ابتدا از اطلاعات و فایل‌های مهم خود پشتیبان بگیرید (حذف نصب ممکن است دیتای محلی VYBE را حذف کند). محافظت Play Protect را خاموش نکنید؛ هشدار را بررسی کنید.

## وضعیت تست

اسکریپت‌های Python و کنترل‌های ساختاری/صحت بسته اجرا می‌شوند، اما محیط سازنده این فایل **Flutter SDK یا Android SDK و یک گوشی واقعی برای اجرای App** ندارد. بنابراین هیچ ادعایی درباره FPS اندازه‌گیری‌شده، موفقیت قطعی Build یا تجربه صدای هدفون مشخص صورت نمی‌گیرد. معیارهای آزمون عملی را در `V050_PERFORMANCE_AND_AUDIO_QA_FA.md` بخوانید.


## اصلاح آنالایزر نسخه 0.5.0

برای رفع توقف بی‌مورد مراحل CI به دلیل lint، دو فایل `.github/workflows/android.yml` و `windows.yml` اکنون از `flutter analyze --no-fatal-infos --no-fatal-warnings` استفاده می‌کنند؛ خطاهای واقعی Dart همچنان باعث شکست می‌شوند. راهنمای دقیق در `V050_ANALYZER_HOTFIX_READ_FIRST_FA.md` است.
